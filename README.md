# Зинурова Амина, группа ЛА-2, Лабораторная работа №2

## Введение

Лабораторная работа посвящена объектно-ориентированному программированию на C#.
Решение всех задач оформлено в одном проекте `var3`, но в разных классах.

В каждом классе присутствуют поля, конструкторы, свойства и перегруженный метод `ToString()`.
Демонстрация работы всех классов и методов — в главном методе `Main` класса `Program`.

Исходные данные вводятся с клавиатуры. Проверка ввода реализована в отдельном классе `Checked`,
который используется во всех задачах.

## Класс `Checked`

**Назначение:** проверка ввода с клавиатуры. Используется один раз — во всех задачах.

**Методы:**
- `ReadInt(prompt)` — читает целое число с проверкой. Если введено не число — просит заново.
- `ReadPositiveInt(prompt)` — читает положительное целое. Если число ≤ 0 или не число — просит заново.
- `ReadDouble(prompt)` — читает вещественное число с проверкой.
- `ReadString(prompt)` — читает непустую строку. Если пусто или только пробелы — просит заново.
- `ReadStringOrNull(prompt)` — читает строку; при нажатии Enter возвращает `null` (значение «не задано»).

## Задание 1.3. Имена

### Класс `Name`

**Назначение:** описывает имя человека — фамилию, личное имя и отчество.

**Поля:**
- `surname` — фамилия (строка).
- `name` — личное имя (строка).
- `patronymic` — отчество (строка).

**Конструкторы:**
- **Первый** — с тремя параметрами `(surname, name, patronymic)`: присваивает все три поля.
- **Второй** — с одним параметром `(name)`: задаёт только личное имя; фамилия и отчество — `null` (используется в задаче 4.5).
- **Третий** — с двумя параметрами `(name, surname)`: задаёт личное имя и фамилию; отчество — `null` (используется в задаче 4.5).

**Свойства:**
- `Surname` — доступ к полю `surname` (get/set).
- `FirstName` — доступ к полю `name` (get/set).
- `Patronymic` — доступ к полю `patronymic` (get/set).

**Методы:** дополнительных методов нет.

**Перегрузка `ToString`:** собирает строку из заданных частей. Если часть равна `null` — она не учитывается. Формат: `"Фамилия Имя Отчество"`.

## Задание 2.3. Человек с родителем

### Класс `HumanWithFather`

**Назначение:** описывает человека с возможностью указать отца.

**Поля:**
- `name` — имя (объект `Name`).
- `height` — рост (целое число).
- `father` — отец (объект `HumanWithFather`).

**Конструкторы:**
- **Первый (главный)** — с тремя параметрами `(Name name, int height, HumanWithFather father)`: все присваивания выполняются здесь. Если у человека нет фамилии, а у отца есть — фамилия наследуется. Если нет отчества, а у отца есть имя — отчество формируется как имя отца + «ович».
- **Второй** — с двумя параметрами `(string nameString, int height)`: вызывает главный конструктор через `: this(...)`.
- **Третий** — с тремя параметрами `(string nameString, int height, HumanWithFather father)`: вызывает главный через `: this(...)`.
- **Четвёртый** — с двумя параметрами `(Name name, int height)`: вызывает главный через `: this(...)`.

**Свойства:**
- `Name` — доступ к имени.
- `Height` — доступ к росту с проверкой.
- `Father` — доступ к отцу.

**Методы:** дополнительных методов нет.

**Перегрузка `ToString`:** возвращает строку вида `"Имя, рост"`. Фамилия и отчество в выводе не участвуют (используются только при формировании имени в конструкторе).

**Примечание:** задача 2.3 закомментирована в `Main`, так как она является вытекающей — задача 4.6 изменяет формат вывода `ToString`. Актуальная версия — 4.6.

### Класс `City`

**Назначение:** описывает город как точку на карте с набором путей к другим городам.

**Поля:**
- `name` — название города (строка).
- `paths` — массив путей к другим городам (массив `Path[]`).

**Конструкторы:**
- **Первый** — с двумя параметрами `(string name, Path[] paths)`: присваивает название и массив путей.

**Свойства:**
- `Name` — доступ к названию города.
- `Paths` — доступ к массиву путей.

**Методы:** дополнительных методов нет.

**Перегрузка `ToString`:** возвращает название города и список связанных городов в виде пар «название:стоимость», разделённых запятыми. Запятая не ставится после последнего элемента.

### Класс `Path`

**Назначение:** описывает путь к другому городу — город и стоимость поездки.

**Поля:**
- `city` — город, к которому ведёт путь (объект `City`).
- `cost` — стоимость поездки (целое число).

**Конструкторы:**
- **Первый** — с двумя параметрами `(City city, int cost)`: присваивает город, проверяет стоимость. Если стоимость неотрицательна — присваивает, иначе выводит ошибку и присваивает 0.

**Свойства:**
- `City` — доступ к городу.
- `Cost` — доступ к стоимости с проверкой (не может быть отрицательной).

**Методы:** дополнительных методов нет.

**Перегрузка `ToString`:** возвращает строку вида `"название:стоимость"`.

**Демонстрация:** создаются шесть городов A, B, C, D, E, F и связи между ними согласно схеме задания.

## Задание 5.2. Кот мяукает

### Класс `Cat`

**Назначение:** описывает кота.

**Поля:**
- `name` — имя кота (строка).

**Конструкторы:**
- **Первый** — с одним параметром `(string name)`: присваивает имя, проверяет его (не пустое и не `null`). Если имя некорректно — выводит ошибку и присваивает «Безымянный».

**Свойства:**
- `Name` — доступ к имени с проверкой (не может быть пустым).

**Методы:**
- `Meow()` — без параметров: выводит `"Имя: мяу!"`.
- `Meow(int n)` — с параметром: выводит `"Имя: мяу-мяу-...-мяу!"`, где количество «мяу» равно `n`. Дефис ставится между «мяу», но не после последнего.

**Перегрузка `ToString`:** возвращает строку вида `"кот: Имя"`.

**Демонстрация:** создаётся кот по имени «Барсик», он мяукает один раз, затем три раза.
